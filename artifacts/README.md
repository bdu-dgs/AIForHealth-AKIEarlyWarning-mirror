# artifacts/ (local only, never committed)

Everything in this folder except this README is ignored by git (`artifacts/*` in `.gitignore`). It holds outputs that are either derived from MIMIC-III patient data, too large for git, or regenerated by the notebooks. Keep it on approved local storage; do not upload or share its contents.

| Path | Produced by | Contents | Patient-level? |
|---|---|---|---|
| `interim/` | `pipeline/01_dataset_construction.ipynb` | Filtered copies of the large MIMIC-III tables (CHARTEVENTS, LABEVENTS, ...) reused to speed up reruns; safe to delete | Yes |
| `models/<run_id>/` | `pipeline/02_ml_pipeline.ipynb` | One folder per fitted model family (`lr__full`, `rf__full`, `lightgbm__full`, `xgboost__full`, `lightgbm__no_dc`): `pipeline.joblib`, `feature_order.json`, `metadata.json`, native boosted-tree files; `run_manifest.json`, `train.log`, aggregate `reports/`; `_heads/` resume checkpoints | Models trained on MIMIC |
| `predictions/<run_id>.parquet` | notebook 02 | Hourly risk for every training out-of-fold and validation snapshot, model and horizon | Yes |
| `predictions/<run_id>_event_replay.parquet` | notebook 02 | Event-driven replay risks for validation patients | Yes |
| `02_ml_pipeline_full_run.ipynb`, `full_run_nbconvert.log` | notebook 02 full run | Executed copy of notebook 02 and its run log | Aggregates only |
| `demo_i/` | `pipeline/demo_i_evaluation.ipynb` | `policy.json` (locked `demo-v1` threshold, monitoring window, alert policy, model hashes), `policy_demo-v0.json`, aggregate validation tables (`*.csv`) and figures (`*.png`) | No |
| `demo_i/site_data/`, `demo_i/shots/`, `demo_i/patients_now.json` | demo runs and screenshots | Local website data, screenshots and time-shifted synthetic patients | No (synthetic) |

The current run is `aki_ml_v1_28e0b1fb83`. The website's model worker and `scripts/score_dashboard.py` load `demo_i/policy.json` and the model in `models/aki_ml_v1_28e0b1fb83/lightgbm__no_dc/`, so the live model runs only on a computer that holds this folder. To rebuild it, rerun notebook 01 (writes `../Cleaned` and `interim/`), notebook 02 (`models/`, `predictions/`) and `demo_i_evaluation.ipynb` (`demo_i/`).
