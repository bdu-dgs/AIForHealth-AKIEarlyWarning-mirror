# artifacts/ (local outputs; policies and aggregate hand-off results are committed)

Everything in this folder except this README, the two `demo_i/` policy files and the aggregate folders under `handoff/` (see below) is ignored by git (see `.gitignore`). It holds outputs that are either derived from MIMIC-III patient data, too large for git, or regenerated by the notebooks. Keep it on approved local storage; do not upload or share its contents.

| Path | Produced by | Contents | Patient-level? |
|---|---|---|---|

| `models/<run_id>/` | `pipeline/02_ml_pipeline.ipynb` | One folder per fitted model family (`lr__full`, `rf__full`, `lightgbm__full`, `xgboost__full`, `lightgbm__no_dc`): `pipeline.joblib`, `feature_order.json`, `metadata.json`, native boosted-tree files; `run_manifest.json`, `train.log`, aggregate `reports/`; `_heads/` resume checkpoints | Models trained on MIMIC |

The current run is `aki_ml_v1_28e0b1fb83`. The website's model worker and `scripts/score_dashboard.py` load `demo_i/policy_feature_v2.json` and the model in `models/aki_ml_v1_28e0b1fb83/lightgbm__no_dc/`, so the live model runs only on a computer that holds this folder. To rebuild it, rerun notebook 01 (writes `../Cleaned` and `interim/`), notebook 02 (`models/`, `predictions/`) and `demo_i_evaluation.ipynb` (`demo_i/`).

For an existing matching run, restore its authorized local `lightgbm__no_dc` model directory at that path. The worker verifies `pipeline.joblib` against `pipeline_sha256` in the policy before loading it. `Setup-AKI.cmd` installs libraries but does not download or train weights. Restoring only `policy.json` is insufficient. Keep the fitted artifact and its provenance files together; do not replace the policy hash to make an unrelated model load.
